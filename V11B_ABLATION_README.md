# VCPulse v1.1b Ablation Research

Research-only runner. Production scanner and UI are untouched.

It measures:
- Sequential funnel from current A baseline through the six frozen v1.1 conditions.
- Leave-one-condition-out variants to identify the main coverage bottleneck.
- 5/10/20-day return, positive rate, MAE and MFE.
- Event-deduplicated statistics so consecutive dates for the same stock are not treated as independent events.
